# AGENTS.md — src/renderer/src/components

The React UI layer (renderer process). Everything the user sees: the sessions of the open project
(one chat pane at a time), sidebar, status bar, title bar, and dialogs. All data flows through
`window.api` (preload) — the renderer never touches Node/Electron directly.

## Key files

| File | Responsibility |
|---|---|
| `SessionPanes.tsx` | Layout of one project's sessions: **every** session stays mounted and only the active slot is shown (`hidden` attribute on the wrapper — CSS, never an unmount) so a session that is not selected keeps streaming/answering. The active session is **controlled** by `App` (`activeId` + `onActiveChange`, remembered per project path so switching workspaces restores the session that was showing); SessionPanes reports the first session when the stored id no longer exists. |
| `Pane.tsx` | A single session pane: header + `ChatPanel`; background badge mode. |
| `PanelToolbar.tsx` | Title bar buttons that toggle the right-side panels for the active session and project: Sub-agents, Terminal, Processes, Browser (with the agent dot), Files, and a More menu (Open Folder, Open in VS Code). |
| `PaneHeader.tsx` | Pane title bar: status dot, git info, menu (inject/log/stop/restart/Open Folder/Open in VS Code/delete — the first four only on the parked PTY path); shows a confirm dialog before deleting a session. |
| `processes/ProcessesOverlay.tsx` | Per-agent **Processes** panel (title bar `Toggle processes`), the sibling of the Files panel: one header tab per background shell (a square Kill button on running shells, so stopping a process does not look like closing a tab) plus a `Monitors (n)` tab, and the selected shell's output streamed live below (store buffer + `data`/`exit` events via `onBackgroundProcData`/`onBackgroundProcExit`, never consuming the agent's `bash_output` read offset). Pools `backgroundProcsList`/`monitorsList` every ~1.5s; subscribes/unsubscribes per selected shell. Reuses `.files-overlay` layout; its width is the shared right-panel column splitter's, not a per-panel drag handle. |
| `ConfirmDialog.tsx` | Reusable confirmation dialog (title, message, confirm/cancel, danger styling), built on `BaseModal`. |
| `common/BaseModal.tsx` | Reusable modal dialog overlay portaled to `document.body` with backdrop click, Escape key handling, accessibility roles, and size modifiers (`sm`, `md`, `lg`, `xl`). Used for app-wide dialogs and popups. |
| `common/BaseDropdown.tsx` | Reusable popover dropdown overlay portaled to `document.body` with smart positioning (auto-flip vertical orientation, auto-clamp horizontal boundaries, and auto max-height overflow scrolling). Used by action menus, pickers, and context dropdowns app-wide. |
| `common/BaseSelect.tsx` | Dedicated option selection control wrapper wrapping `BaseDropdown` with combobox/listbox ARIA semantics for option pickers. |
| `Sidebar.tsx` | Left sidebar: header action bar with a vertical menu holding a single "New session" row (`Plus` icon, no border radius or bottom border); adding a folder as a project lives in the new session's footer project picker, and project list with an expand/collapse chevron per row. An expanded project lists its sessions — status dot (green running / yellow waiting / no dot when idle), active row highlighted, and a per-row `...` menu (Rename via inline input, Stop when running, Delete). The row `+` activates a draft session (lazy creation, materialized on first prompt); deleting a project's last session transitions the workspace to a draft session pane. Expanded state persists in `localStorage` (`meow.sidebar.expanded`). Shows a red badge (count) per project whose sessions are waiting on a permission/question prompt (`needsInput` prop). |
| `StatusBar.tsx` | Bottom status bar: redesigned with Lucide icons (`Folder`, `FolderSymlink`, `Code`, `GitBranch`, `Bot`, `Globe`, `Tag`), active indicator dot, quick "Folder" & "VS Code" action buttons, dirty count badge, interactive Git & Browser Bridge status pills, and app version display. |
| `TitleBar.tsx` | Custom window chrome (min/max/close) for frameless platforms; when sidebar is collapsed, hovering the brand section reveals a floating sidebar popover dropdown menu. |
| `PopupTitleBar.tsx` | Popup window chrome for the FileViewer/GitViewer BrowserWindows: drag region + (Linux) custom min/max/close, mirroring the main TitleBar so popups match the app theme. |
| `EmptyState.tsx` | Shown when no pane is open (workspace vs. no-workspace hint). |
| `BackgroundPanel.tsx` | Lists background agents; open/stop/delete them (delete shows a confirm dialog). |
| `UpdateDialog.tsx` | Auto-update status + install prompt. Only a manual check opens it (a background download stays out of the way); during a background download it is dismissible and hides the install button. |
| `BrowserDialog.tsx` | Chrome bridge status + extension approval UI: white background cards, Lucide icons, status pill indicators, an Allow/Deny card for a pending extension, a trusted-extension list with revoke, and quick setup navigation. |
| `InstallGuideDialog.tsx` | Extension install steps for browser bridge: redesigned with numbered step cards (1-4), Lucide icons, copyable unpacked extension directory path box, and local security notice banner. |
| `files/FilesOverlay.tsx` | In-app Files explorer (pane `⋮` → Files), docked on the right of the pane area by default (drag its left edge to resize, 320–900px, default 420px) or expanded over the whole pane area via maximize/restore: filter + tree on the left (drag the splitter between tree and tabs to resize the tree, min 160px with ≥ 160px left for the editor; persisted in `localStorage` `meow.files.sideWidth`, double-click resets to the default), open files as header tabs on `common/PanelHeader`, each kept mounted (hidden when inactive) so a tab switch keeps unsaved edits; header menu (Focus filter, Refresh, Collapse all, Close all tabs, Copy path, Reveal in Folder, Open in VS Code), close. `Ctrl/Cmd+S` saves; an unsaved file shows a dot after its name; closing one asks to discard it. `Esc` closes the panel unless something is unsaved. `App` asks before discarding when the panel closes (its close button, the title bar button, or a project switch; keeping the edits on a switch returns to that project), and keeps one React tree in a portal whose DOM node moves between the docked and expanded slots, so expanding keeps tabs, edits and undo. |
| `files/FilesTree.tsx` | Lazy tree of the overlay — lists dotfiles and `node_modules`, name filter, `?`-prefixed content search (`path:line` hits), background refresh on context changes. |
| `file-content/FileContentView.tsx` | Toolbar + body of a file (CodeMirror syntax-highlighted editor with line numbers and live auto-indent, rendered markdown preview toggle for `.md`, `Ctrl+S`/`Cmd+S` keyboard shortcut for the `active` instance), shared by the popup `FileViewer` window and the overlay tab. The popup also shows Save, Copy and Open in VS Code; the Files panel passes `hideFileActions` and shows the unsaved state on its tab through `onDirtyChange`. |
| `git/` | Redesigned Git viewer popup window with resizable sidebars: Changes tab (staged/unstaged file list, file search filter, status badges, diff view toggle), History tab (commit list with search filter, author avatars, compare mode, commit detail card, diff view), Blame tab (workspace file tree, line blame annotations), and branch switcher dropdown with search filter and branch creation. |
| `terminal/TerminalOverlay.tsx` | Session terminal panel: a right-hand panel on `common/PanelHeader` that joins the shared right-panels grid with Files/Processes/Subagent panels and can expand over the pane area. Tabs (status dot, exit code, double-click rename, close), `+` new terminal, Restart on an exited tab, tab context menu, process cap error row. Open state lives in `App` (`terminalOpenFor`), toggled per session by the pane header button or `Ctrl+``. |
| `browser/BrowserOverlay.tsx` | Built-in browser panel (right-hand, joins the right-panels grid): tabs from `browserTabsList` + `onBrowserTabsChanged`, tab context menu (`BaseDropdown`), `common/PanelHeader` with `+`, console toggle, a menu (Open in default browser), expand and close, then toolbar + control banner + viewport. Tabs live in main, so expanding remounts the panel without reloading the page. |
| `browser/BrowserToolbar.tsx` | Back/forward/reload-stop, address field (bare hosts → https, loopback → http via `normalizeUrlInput`; Enter navigates, Escape reverts), Open in default browser (`browserOpenExternal`). Disabled while the agent owns the tab. |
| `browser/BrowserControlBanner.tsx` | Control banner: Take over (`agent`), Hand back / I'm signed in (`user`), the approval waiting text (`approval`). |
| `browser/BrowserViewport.tsx` | Attaches/detaches the native panel and sends the placeholder rect (rAF-coalesced, rounded, skipped when unchanged/zero); empty state and crashed-tab Reload. |
| `terminal/TerminalView.tsx` | xterm.js instance with FitAddon, buffer-before-attach data stream, resize observer, and right-click context menu (send selection/tail to chat). Always dark in every app theme: colors come from `--terminal-bg`/`--terminal-fg` (not overridden by the light theme), which also paint the panel body and the xterm viewport. |
| `chat/` | The native-agent chat UI — see its own AGENTS.md. |
| `settings/` | Settings dialog + tabs — see its own AGENTS.md. |

## Conventions

- **Never** import from `electron` or `node:*` here; use `window.api` (typed `AgentApi`).
- **Use Common Components:** UI popups, dropdown menus, context menus, and option selectors MUST use common components (`src/renderer/src/components/common/BaseDropdown.tsx`, `BaseSelect.tsx`) rather than creating custom overlay positioning or popover logic.
- `App.tsx` (parent) owns the mounted runtimes and the active session per project; components stay
  presentational-ish.
- A session that is not showing must stay mounted (see `SessionPanes`) — never conditionally render,
  key or unmount it, or its run stops.
- UI labels and system-style notices from main (with `[meow]` prefix) are English.
