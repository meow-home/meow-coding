# AGENTS.md — src/renderer/src/components

The React UI layer (renderer process). Everything the user sees: the sessions of the open project
(one chat pane at a time), sidebar, status bar, title bar, and dialogs. All data flows through
`window.api` (preload) — the renderer never touches Node/Electron directly.

## Key files

| File | Responsibility |
|---|---|
| `SessionPanes.tsx` | Layout of one project's sessions: **every** session stays mounted and only the active slot is shown (`hidden` attribute on the wrapper — CSS, never an unmount) so a session that is not selected keeps streaming/answering. The active session is **controlled** by `App` (`activeId` + `onActiveChange`, remembered per project path so switching workspaces restores the session that was showing); SessionPanes reports the first session when the stored id no longer exists. |
| `Pane.tsx` | A single session pane: `ChatPanel` only (the session identity lives in the title bar, there is no header row); background badge mode. |
| `PanelToolbar.tsx` | Title bar buttons that toggle the panels for the active session and project: Sub-agents, Terminal, Tasks, Browser (with the agent dot), Files, Git, and a More menu (Open Folder, Open in VS Code). Tasks is a right-hand panel with its own title header (no tabs), Files the docked explorer and Git the read-only changes/log panel. |
| `SessionTitle.tsx` | The active session's identity, seated in the window title bar between the brand and `PanelToolbar`: status dot (the accessible status name), the ellipsized session name, and the `⋮` menu (Open Folder / Open in VS Code / Delete session, the last behind a confirm dialog). The name shrinks so it never pushes the tools; with the sidebar collapsed the brand strip shrinks too, so the title sits next to the expand button. |
| `processes/TasksPanel.tsx` | The session's **Tasks** panel (title bar `Toggle tasks`): a right-hand column panel like Files, with **one expandable list** instead of tabs — background sessions, background shells, polled commands and delegations, grouped `Active` / `Finished`. A row is an identity badge + label + `kind · id` + state chip + elapsed/age; clicking it expands the row in place (multi-open) to facts, content and actions. The badge says what is running, not its state (no state dot): the Meow mark for a native session, `Users` for a sub-session or a sub-session delegation, `Terminal` for a background shell, `RefreshCw` for a poll and the Antigravity logo when the watch carries `cliAgentId`. Content per kind: the last two messages (`listChatMessages`), the live output box (`backgroundProcSubscribe` on expand, `backgroundProcUnsubscribe` on collapse, via `onBackgroundProcData` — never consuming the agent's `bash_output` read offset), or the resolved watch's result. Actions: `Open session`/`Stop`/`Delete` (confirm), `Kill process` (a labelled button, never a tab ×), `Stop watching`/`Dismiss` (`monitorsCancel`), `Open session` for a delegation watch. Header: title, count, maximize and close; docked it joins `.right-panels-grid`, maximized (`.full`) it covers the pane area. Polls `backgroundProcsList`/`monitorsList` every ~1.5s; a `focus` prop (`{ monitorId?, seq }`, from the chat's background-tasks card) expands that watch once, then reports back through `onFocusApplied`. |
| `ConfirmDialog.tsx` | Reusable confirmation dialog (title, message, confirm/cancel, danger styling), built on `BaseModal`. |
| `common/BaseModal.tsx` | Reusable modal dialog overlay portaled to `document.body` with backdrop click, Escape key handling, accessibility roles, and size modifiers (`sm`, `md`, `lg`, `xl`). Used for app-wide dialogs and popups. |
| `common/BaseDropdown.tsx` | Reusable popover dropdown overlay portaled to `document.body` with smart positioning (auto-flip vertical orientation, auto-clamp horizontal boundaries, and auto max-height overflow scrolling). Used by action menus, pickers, and context dropdowns app-wide. |
| `common/BaseSelect.tsx` | Dedicated option selection control wrapper wrapping `BaseDropdown` with combobox/listbox ARIA semantics for option pickers. |
| `Sidebar.tsx` | Left sidebar: header action bar with a vertical menu holding a single "New session" row (`Plus` icon, no border radius or bottom border); adding a folder as a project lives in the new session's footer project picker, and project list with an expand/collapse chevron per row. An expanded project lists its sessions — status dot (green running / yellow waiting / no dot when idle), active row highlighted, and a per-row `...` menu (Rename via inline input, Stop when running, Delete). A delegated **sub-session** (`SessionMeta.parentAgentId`) is rendered one indent deeper directly under its parent with a `CornerDownRight` glyph and a `Sub-session of <parent>` tooltip. The row `+` activates a draft session (lazy creation, materialized on first prompt); deleting a project's last session transitions the workspace to a draft session pane, and adding a folder as a project registers it without creating a default `meow` session (same lazy creation). Expanded state persists in `localStorage` (`meow.sidebar.expanded`). Shows a red badge (count) per project whose sessions are waiting on a permission/question prompt (`needsInput` prop). |
| `StatusBar.tsx` | Bottom status bar: redesigned with Lucide icons (`Folder`, `FolderSymlink`, `Code`, `GitBranch`, `Bot`, `Globe`, `Tag`), active indicator dot, quick "Folder" & "VS Code" action buttons, dirty count badge, interactive Git & Browser Bridge status pills, and app version display — the Git pill adds `↑N` (unpushed) / `↓N` (behind) next to the branch and its tooltip spells out the upstream state; the version slot becomes an "Update available" / "Updating 42%" / "Restart to update" pill while an update is pending (`update`/`onUpdateClick`). |
| `TitleBar.tsx` | Custom window chrome (min/max/close) for frameless platforms; when sidebar is collapsed, hovering the brand section reveals a floating sidebar popover dropdown menu. Renders the `session` slot (the active session's `SessionTitle`) between the brand and the tools. |
| `PopupTitleBar.tsx` | Popup window chrome for the FileViewer BrowserWindow: drag region + (Linux) custom min/max/close, mirroring the main TitleBar so popups match the app theme. |
| `EmptyState.tsx` | Shown when no pane is open (workspace vs. no-workspace hint). |
| `UpdateDialog.tsx` | Auto-update status + install prompt (version pair, release notes, progress). Only a manual check — or the status-bar pill / toast — opens it; "Update & Restart" during a background download defers the restart until it finishes and "Keep working" cancels it. |
| `UpdateToast.tsx` | Bottom-right notice when a background download finishes: the body opens `UpdateDialog`, "Restart now" installs, "Later" dismisses it for that version. Paired with the status bar pill, it replaces relying on the OS notification alone. |
| `BrowserDialog.tsx` | Chrome bridge status + extension approval UI: white background cards, Lucide icons, status pill indicators, an Allow/Deny card for a pending extension, a trusted-extension list with revoke, and quick setup navigation. |
| `InstallGuideDialog.tsx` | Extension install steps for browser bridge: redesigned with numbered step cards (1-4), Lucide icons, copyable unpacked extension directory path box, and local security notice banner. |
| `files/FilesOverlay.tsx` | In-app Files explorer (pane `⋮` → Files), docked on the right of the pane area by default (drag its left edge to resize, 320–900px, default 420px) or expanded over the whole pane area via maximize/restore: editor on the left, filter + tree on the right (drag the splitter on the tree's left edge to resize it — dragging left widens it — min 160px with ≥ 160px left for the editor; persisted in `localStorage` `meow.files.sideWidth`, double-click resets to the default), open files as header tabs on `common/PanelHeader` (the shared `.panel-tab` style: the only differences are the italic name of a preview tab and the pin button), each kept mounted (hidden when inactive) so a tab switch keeps unsaved edits; a single click opens a preview that the next single click replaces, a double click opens permanent or promotes the preview, a dirty file is promoted, the pin button (visible on hover and on the active tab, filled when pinned) makes a tab permanent and sorts it first, and Close all tabs keeps pinned tabs. A per-file bar (`.files-bar`, reusing `.viewer-toolbar`) spans the full panel width between the header and `.files-body`: the active file portals it into a host element (the empty state renders its own bar there, so the bar does not jump when the first file opens), with the project-relative path on the left and, on the right, the file's own actions plus Toggle file tree (persisted in `localStorage` `meow.files.treeHidden`, hiding the tree with `hidden` so its expanded folders survive) and the Files menu (Focus filter — which shows the tree first when hidden —, Refresh, Collapse all, Close all tabs, Copy path, Reveal in Folder, Open in VS Code). It takes the panel's project's active session as `agentId` and builds each tab's send-line gutter extension once per path, reading the target through a ref so switching sessions never rebuilds the editor; with no session the gutter is absent. `Ctrl/Cmd+S` saves; an unsaved file shows a dot after its name; closing one asks to discard it. `Esc` closes the panel unless something is unsaved. `App` asks before discarding when the panel closes (its close button, the title bar button, or a project switch; keeping the edits on a switch returns to that project), and keeps one React tree in a portal whose DOM node moves between the docked and expanded slots, so expanding keeps tabs, edits and undo. |
| `files/FilesTree.tsx` | Lazy tree of the overlay — lists dotfiles and `node_modules`, name filter, `?`-prefixed content search (`path:line` hits), background refresh on context changes. A directory row is its 14px chevron plus the name (no folder icon) and a file row puts its typed `file-icon` in the same slot, so both start at the same x at a given depth; rows are 2.166667rem rounded pills (`.files-tree-slot`, `--menu-hover` / `--menu-active`, `--radius`, 1rem indent per level). In a git repository a changed file tints its name and shows its status letter at the row's right edge, a changed directory shows a dot, and the status is fetched once per debounce (mount, `reloadToken`, context refresh) through `git-decorations`. A row click opens a preview (`onOpenFile`); a file row double click opens permanent or promotes the preview (`onOpenFilePermanent`). |
| `files/line-send-gutter.ts` | `buildSendText` / `languageLabel` / `lineSendGutter`: a CodeMirror gutter (highest precedence, so before the line numbers) with a `+` on the hovered line; a click sends that line — or the selected lines, when the click is inside a non-empty selection — to the target session's composer through `meow:composer-insert`, as a fenced block headed by the project-relative `path:line` with a fence longer than any backtick run. |
| `files/open-tabs.ts` | Pure tab rules over `{ tabs, activeTab }`: `openTab` (single click preview, double click permanent, an open file only activates, a preview is replaced in place), `promoteTab` (double click, or a file becoming dirty), `togglePinned` (permanent + sorts first), `closeTabs`, `closeAllTabs` (keeps pinned), `activateTab`. |
| `files/file-icon.tsx` | `fileIconKind` / `fileIconFor` / `FileIcon` — maps a file name to a lucide icon and a colour class (code, JSON, Markdown, image, styles, config, `.gitignore`, generic); the colours live in `styles.css` as theme tokens. |
| `files/git-decorations.ts` | Pure git status helpers: `buildGitDecorations` (porcelain path → letter `M`/`A`/`D`/`R`/`T`/`U` + colour kind, ancestor directories, untracked-directory prefixes, quote stripping), `decorationFor`, `directoryDecoration`, `projectRelativePath`. No `node:path` in the renderer. |
| `file-content/FileContentView.tsx` | Toolbar + body of a file (CodeMirror syntax-highlighted editor with line numbers and live auto-indent, rendered markdown preview toggle for `.md`, `Ctrl+S`/`Cmd+S` keyboard shortcut for the `active` instance), shared by the popup `FileViewer` window and the overlay tab. The popup also shows Save, Copy and Open in VS Code; the Files panel passes `hideFileActions`, which makes the toolbar the panel's per-file bar (`files-bar`): it labels the file by its path inside `root` and adds one Fold all / Unfold all toggle (`foldAll` / `unfoldAll` from `@codemirror/language`, state kept per open file) for anything shown in the editor, plus the host's `toolbarActions` (tree toggle and Files menu). `toolbarHost` portals the bar into the panel's full-width host, and an inactive tab renders no toolbar at all. `extraExtensions` appends the Files panel's send-line gutter (memoized with the language extensions, so typing never reconfigures the editor); the popup passes none. The panel shows the unsaved state on its tab through `onDirtyChange`. |
| `git/` | The docked Git panel (`GitPanel`): read-only, no staging/commit/branch switching. `Changes` tab (`GitChangesView`): flat `Staged` / `Changes` groups with a status letter per row, and a click expands that file's diff in place (the same path appears in both groups when it has staged and unstaged edits, each row showing its own side). `History` tab (`GitHistoryView`): a filter field, a flat commit list (subject, short sha, author, relative time, and a yellow circled up-arrow as the row's trailing element on commits the upstream does not have), a click expands the commit's message and changed files with `+/−` counts, and clicking a file swaps the list for that file's diff with a back row. Header: the two tabs, a read-only branch chip (branch name + `↑N` unpushed / `↓N` behind, a cloud-off icon when the branch has no upstream, all explained in its tooltip) and Refresh; `GitDiffView` + `parseDiff.ts` render the diffs. The panel re-reads `gitGetStatusDetail` every 2.5s and reloads the log only when the status signature moves, so a commit made by the agent (or in a terminal) lands without a manual refresh — an unchanged poll never collapses an open diff or commit. |
| `terminal/TerminalOverlay.tsx` | Session terminal panel: a right-hand panel on `common/PanelHeader` that joins the shared right-panels grid with the Files, Tasks and Subagent panels and can expand over the pane area. Tabs (status dot, exit code, double-click rename, close), `+` new terminal, Restart on an exited tab, tab context menu, process cap error row. Open state lives in `App` (`terminalOpenFor`), toggled per session by the title bar button or `Ctrl+``. A `pendingCommand` from a chat command box is consumed once, after the initial tab list lands: into the selected running tab, else the first running one, else a restarted tab, else a new tab created with the command; a pending command suppresses the panel's own auto-create, so it never opens an empty duplicate tab. |
| `browser/BrowserOverlay.tsx` | Built-in browser panel (right-hand, joins the right-panels grid): tabs from `browserTabsList` + `onBrowserTabsChanged`, tab context menu (`BaseDropdown`), `common/PanelHeader` with `+`, console toggle, a menu (Open in default browser), expand and close, then toolbar + control banner + viewport. Tabs live in main, so expanding remounts the panel without reloading the page. |
| `browser/BrowserToolbar.tsx` | Back/forward/reload-stop, address field (bare hosts → https, loopback → http via `normalizeUrlInput`; Enter navigates, Escape reverts), Open in default browser (`browserOpenExternal`). Disabled while the agent owns the tab. |
| `browser/BrowserControlBanner.tsx` | Control banner: Take over (`agent`), Hand back / I'm signed in (`user`), the approval waiting text (`approval`). |
| `browser/BrowserViewport.tsx` | Attaches/detaches the native panel and sends the placeholder rect (rAF-coalesced, rounded, skipped when unchanged/zero); empty state and crashed-tab Reload. |
| `terminal/TerminalView.tsx` | xterm.js instance with FitAddon, buffer-before-attach data stream, resize observer, and right-click context menu (send selection/tail to chat). Always dark in every app theme: colors come from `--terminal-bg`/`--terminal-fg` (not overridden by the light theme), which also paint the panel body and the xterm viewport. |
| `chat/` | The native-agent chat UI — see its own AGENTS.md. |
| `settings/` | Settings dialog + tabs — see its own AGENTS.md. |

## Conventions

- **Never** import from `electron` or `node:*` here; use `window.api` (typed `AgentApi`).
- **Use Common Components:** UI popups, dropdown menus, context menus, and option selectors MUST use common components (`src/renderer/src/components/common/BaseDropdown.tsx`, `BaseSelect.tsx`) rather than creating custom overlay positioning or popover logic.
- `App.tsx` (parent) owns the mounted runtimes and the active session per project; components stay
  presentational-ish.
- A session that is not showing must stay mounted (see `SessionPanes`) — never conditionally render,
  key or unmount it, or its run stops.
- UI labels and system-style notices from main (with `[meow]` prefix) are English.
