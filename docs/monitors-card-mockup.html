Hành vi

  • Card là item riêng trong feed: có id riêng (vd tasks:<sessionId>), render ngoài mọi step/tool group và ngoài message list của lượt.
  • Update tại chỗ bằng push event (monitorsChanged), không tạo item mới mỗi lần monitor đổi → không làm nhảy vị trí feed.
  • Sticky top (khuyến nghị): luôn thấy khi cuộn; inline: nằm đúng chỗ được chèn, cuộn theo chat.
  • Hết việc: card chuyển “all done” rồi tự ẩn sau ~30s (hoặc bấm ✕ để dismiss ngay).
  • Click header = thu/mở; click dòng = mở pane + chọn mục; ✕ = kill/stop watching/dismiss; footer link = mở pane.

Cần đổi gì trong code

  • ChatPanel feed item mới: { kind: 'tasks' } chèn một lần/session, keyed cố định; không đưa vào groupToolCalls.
  • MonitorInfo thêm: kind, label, status, startedAt, sessionId, detail.
  • Push event monitorsChanged (main → renderer) thay poll 1.5s của ProcessesOverlay.
  • Component mới: components/chat/BackgroundTasksCard.tsx; pane: tách MonitorsPane, mở rộng ProcessesOverlay.
  • Sticky cần position: sticky; top trong .chat-feed + nền đặc để message không lộ qua.
