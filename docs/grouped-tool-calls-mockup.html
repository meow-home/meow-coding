Grouped tool-call clusters — 3 layout options

Each panel below shows the same chat segment: a user prompt, an assistant thought, then four tool calls in a row, then a follow-up assistant line. The only thing that changes between options is how the four tool calls are grouped. Reasoning lines and assistant text stay independent, per the spec. Light/dark toggle at the top to see both themes.

All three options collapse by default. Click "Ran 4 commands" to expand. Inside, each tool still expands independently.
