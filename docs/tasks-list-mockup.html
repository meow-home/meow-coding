Redesign v3 · Meow desktop

Tasks — one expandable list in the right panel. No tab strip.

The Processes panel keeps its right-hand slot; the tab strip is what goes away. Background shells, polls, delegations and background sessions all live in one list. A row is a one-line summary (state · name · kind · elapsed); clicking it expands it in place to show the live output, the result, the last messages — and the actions. Maximize still covers the pane area.

Row anatomy

  • state dot — green running, blue waiting, yellow needs-you, grey finished, red error
  • kind icon — session · shell · poll · delegation (one glyph each)
  • label — session name, or the command in mono
  • sub-label — kind + short id / cwd
  • state chip — the exact state, not just a colour
  • elapsed — live while active, “1m ago” once finished

Expanded body: facts (mono kv) → content (output / result / last messages) → actions. Content is clamped; long output scrolls inside its own box so the row never grows past ~9rem.

Only live rows pulse. A needs-you row keeps a yellow inset bar, so it is visible from the chat behind the panel.

Actions per kind

RowActions
session · activeOpen session · Stop · Delete
session · stoppedOpen transcript · Delete
shell · runningKill process · Copy output · Delete
shell · exitedCopy output · Dismiss
poll / delegation · waitingStop watching · Open sub-session
monitor · resolvedDismiss · Open sub-session

Destructive actions sit at the far right and never look like the old tab ×. Kill is labelled “Kill process”, not an icon alone.

Behaviour

  • Multi-open: two shells can be compared side by side; the list scrolls, not the pane.
  • Expansion is keyed by row id, so a push event or a re-sort never collapses what you opened.
  • Rows keep their position while expanded — a watch resolving does not move the row under the cursor.
  • Live output subscribes on expand, unsubscribes on collapse (same lifecycle the overlay uses today).
  • Elapsed ticks once per second; finished rows show a coarse age instead.
  • Header is a <button aria-expanded aria-controls>; the action row is a sibling, never nested.
  • Tab rows, Enter/Space toggles, Esc closes the open row, then the panel.
