One window · many sessions

Run six coding sessions at once. None of them wait for you.

Meow Coding is a desktop app built around a first-party coding agent. Every session gets a pane and stays mounted, so the ones you are not looking at keep working. The transcript, tool calls, permissions, cost and file edits are all in the app — nothing is a black box.

Inside a session

what the agent can do

A session is a chat with the Meow agent. It reads and writes your files, runs commands, searches the web, drives a browser, and asks before it does anything you have not allowed.

Parallel

Sessions that keep running

Create, rename, stop or delete a session from its sidebar row. Move one to the background and it keeps going while you work elsewhere.

Control

Permissions you set once

Per-tool allow, ask or deny with wildcard patterns, plus a read-only plan mode for analysis you do not want touching files.

Recovery

Undo a whole turn

Every turn snapshots the files it touched. Undo restores the files and trims the transcript; redo puts both back.

Context

Compaction before the wall

As a session approaches its context limit, older turns are summarized with a verbatim tail kept intact — so long sessions keep their thread.

Cost

What each run cost

Tokens and dollars per session and per model, cache reads included, priced from the models.dev catalog.

Steering

Talk to it mid-turn

Messages sent while a turn is running are queued and injected at the next step, so you can redirect without stopping the work.
