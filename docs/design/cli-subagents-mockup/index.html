CLI Agents — mockup

Antigravity CLI and OpenCode as their own agents: install, sign in, keep accounts, give them tasks directly, and let a Meow session delegate to them the way Claude delegates to Meow. Companion to the design spec.

Settings → CLI Agents
1 · Settings, agents & accounts Runtime cards (installed / missing / needs login), agent list per runtime, add-account flows for Google sign-in, Gemini API keys and OpenCode providers, delegation settings, defaults and concurrency.
CLI agent session
2 · Agent session (direct tasks) A first-class session in the sidebar: give the agent any task, watch its own tool steps and streamed text, handle a blocked permission, continue the conversation, stop the run.
Meow → CLI delegation
3 · Delegation from Meow A Meow session delegates a task into a CLI session, keeps working while it runs, verifies the result, then sends feedback into the same CLI conversation.

What the mockup assumes

  • CLI agents are peer workers with their own sessions, not restricted Meow sub-agents. They keep their own loop, tools, permission engine, context and conversation history.
  • A CLI session lives in the sidebar, grouped by agent, next to Meow sessions.
  • Meow delegates with delegate_cli: queue → run → result wakes the Meow session → verify → feedback in the same CLI conversation (max 3 rounds).
  • Antigravity keeps one Google account active per machine; saved sign-ins are opt-in experimental. Gemini API key agents and OpenCode profiles run in parallel.
  • Headless CLIs cannot ask Meow for permission, so “ask” becomes block, report, and offer allow & retry.

Decisions locked

  • Direction approved: CLI agents are worker sessions, and Meow delegates with delegate_cli (queue → result wake → verify → feedback).
  • Antigravity accounts: A + C supported (Google re-login + Gemini API key agents); B keyring snapshots experimental and off by default.
  • Delegation reuses one CLI session per plan/project; feedback continues the same conversation (3 rounds).
  • Default agent mode is edit inside the workspace; full is per agent and explicit.
