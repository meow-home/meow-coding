agy Add Antigravity agent — Gemini API key

API-key agents are fully isolated: each task gets modelProvider: "gemini" and its own GEMINI_API_KEY. They run in parallel with a signed-in Google agent, but use Google AI Studio quota instead of your subscription.

gemini-3.8-flash-high ▾

The key is stored in the vault; it never reaches the renderer after saving.

Save current sign-in for switching
!
Experimental. Antigravity CLI has no profile flag, so Meow reads the OS keyring entry (gemini / antigravity) and restores it when an agent is activated. The swap is machine-wide, needs every agy process closed, and may break when Google changes the CLI.
  • The credential is encrypted with the OS keystore before it is written to disk.
  • Meow verifies each restore with a tiny test run; a failure marks the agent “needs login”.
  • Only agents you explicitly save are copied. Removing the agent wipes the copy.

Meow will finish or pause its Antigravity tasks, restore the saved sign-in for doanp@company.com, then verify it. Switching takes about a second; other terminal sessions using agy must be closed first.
